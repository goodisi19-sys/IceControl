# IceControl 0.1.0 — BLE-диагностика

Android-приложение для исследования BLE-протокола кулера OnePlus PCV14 / Ice Card Mini.

## Возможности
- поиск BLE-устройств;
- подключение и получение GATT-служб/характеристик;
- чтение характеристик с READ;
- вывод значений в HEX в журнал.

## Важно
Управление скоростью пока не реализовано. Известные UUID и свойства характеристик не раскрывают формат управляющих команд. Запись не выполняется, чтобы не отправлять кулеру непроверенные данные.

## Сборка
Открой папку проекта в Android Studio (JDK 17, Android SDK 35), дождись Gradle Sync и выбери Build → Build APK(s).

GitHub Actions собирает debug APK при каждом push в main. Файл доступен в разделе Actions → последний запуск → Artifacts.

## Диагностика
При тестировании скопируй журнал из приложения и пришли его сюда вместе с описанием действия, после которого возникла ошибка.
